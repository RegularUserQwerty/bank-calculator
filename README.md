В проекте используется: MAIL_MAILER=log
Поэтому письма не отправляются на реальные почтовые адреса, а записываются в файл логов Laravel.

Файл логов: storage/logs/laravel.log
Логика отправки писем реализована и может быть подключена к реальному SMTP-серверу без изменения кода приложения.

Проект может быть запущен локально:

composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
